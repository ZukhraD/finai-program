# Финансовый анализ + ИИ

Программа самообучения: комплексный финансовый анализ юрлиц РК с применением ИИ.
10 модулей, интенсив на 12 рабочих дней по 3–4 часа.

Сайт — один файл `index.html` без сборки. Отметки о прохождении хранятся в браузере.

## Публикация
- **GitHub Pages:** Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
- **Vercel:** Add New → Project → импорт репозитория, без настроек сборки.
